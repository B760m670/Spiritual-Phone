# Spiritual Phone 📱👻

Android-приложение в эстетике **духовного телефона (Denreishinki / Soul Pager)** из аниме *Bleach*.
Цель — реалистичный «детектор пустых»: приложение ловит реальные физические аномалии
(на старте — аномалии магнитного поля через магнитометр телефона) и интерпретирует их
в эстетике Bleach — обнаруженные «пустые» отображаются точками на карте, с уведомлениями и звуками.

> Научно честная трактовка: приложение детектирует **электромагнитные аномалии** и подаёт их
> в визуальном языке Bleach. Это художественная оболочка над реальными показаниями датчиков.

## Технологии

| Область | Выбор |
|---|---|
| Язык / UI | Kotlin + Jetpack Compose |
| Карта | MapLibre (схематичная вектороная, без API-ключа) |
| Сборка | Gradle + GitHub Actions → APK |
| Мин. Android | 8.0 (API 26) |

## Дорожная карта (milestones)

- **M1 — Каркас (текущий):** проект собирается в APK через CI, схематичная карта, GPS-позиция игрока, запрос разрешений.
- **M2 — Детекция:** магнитометр, порог аномалии → «обнаружение реацу», класс пустого по силе сигнала.
- **M3 — Карта духов:** маркеры пустых относительно игрока (направление по компасу + сила сигнала), исчезновение (синигами).
- **M4 — Лор и медиа:** виды пустых (Gillian / Adjuchas / Vasto Lorde), имена, фото, звуки (Гарганта, тревога), уведомления.
- **M5 — In-app обновления:** проверка GitHub Releases → скачивание/установка APK без Play Store.
- **M6+ —** барометр/инфразвук как уточнение сигнала, дизайн вкладок, настройки.

## Сборка

Локально (нужен Android SDK):

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/
```

В CI APK собирается автоматически на каждый push и доступен как artifact во вкладке Actions.

## Разрешения

- `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` — позиция игрока на карте.
- `INTERNET` — загрузка стиля карты.
- Магнитометр (compass) — для детекции (M2), разрешений не требует.
